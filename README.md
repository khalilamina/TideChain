# TideChain

TideChain enables high-performance, real-time data processing on a distributed ledger network, facilitating scalable hub operations.

TideChain is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/TideChain.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

TideChain is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
